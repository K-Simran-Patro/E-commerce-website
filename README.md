## 🌸 About the Project

A full-stack e-commerce web application designed to simulate a real-world online shopping experience.  
This project focuses on building scalable backend systems, clean UI design, and handling real-time events using modern technologies ✨

- ☕ Java  
- 🌐 HTML  
- 🎨 CSS  
- ⚡ JavaScript  
- 🗄️ PostgreSQL

✨ User authentication (login/signup)  
✨ Product listing and browsing  
✨ Add to cart & order management  
✨ Backend event handling using Kafka
